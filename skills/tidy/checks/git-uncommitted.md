## 감지 조건

현재 디렉토리가 git 레포면 항상 수행한다 (`git rev-parse --is-inside-work-tree`).

## 검사 절차

```bash
git status --short
git log --oneline @{upstream}..HEAD 2>/dev/null   # 미푸시 커밋 (upstream 없으면 생략)
git stash list
```

1. **미커밋 변경**: 수정 파일과 미추적 파일 중 이번 세션에서 만들거나 고친 것을 대화 컨텍스트와 대조해 가려낸다. 세션과 무관한 기존 더티 파일은 구분해서 표기한다.
2. **미푸시 커밋**: upstream 대비 로컬에만 있는 커밋.
3. **stash 잔여물**: 이번 세션에서 만든 stash가 남아 있는지.
4. **임시 파일**: 세션 중 생성한 스크린샷이나 스크래치 파일이 작업 디렉토리에 남아 있는지.

## 처리

- 미커밋 변경: 커밋 단위를 제안하고 (프로젝트 커밋 컨벤션 준수) 승인 후 커밋
- 미푸시 커밋: 푸시 여부 확인
- 임시 파일: 삭제 대상인지 확인 후 삭제. **판단이 애매한 파일은 지우지 말고 보고만 한다**
