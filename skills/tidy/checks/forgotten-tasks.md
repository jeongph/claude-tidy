## 감지 조건

항상 수행한다. 컨텍스트가 쌓이면서 초반 약속이 잊히는 것은 모든 세션에서 일어날 수 있다.

## 검사 절차

1. **대화 되짚기**: 세션 처음부터 훑으며 "하기로 한 것"을 모두 수집한다 —
   - 사용자의 최초 요청과 추가 요청 (중간에 끼어든 요청 포함)
   - "나중에", "이따가", "그건 따로", "일단 이것부터" 같은 표현으로 미뤄진 항목
   - 스스로 "~도 해야 한다", "~는 이후에 처리"라고 말해놓은 항목
   - 계획/투두 목록에 있었지만 완료 표시가 안 된 항목
2. **수행 여부 대조**: 수집한 각 항목이 실제로 수행됐는지 확인한다. "말만 하고 안 한 것"과 "사용자가 명시적으로 취소한 것"을 구분한다.
3. `docs/tasks.md` 같은 작업 상태판이 있으면 진행중 항목과 실제 상태를 대조한다 — 완료됐는데 남아 있거나, 진행 중인데 반영 안 된 항목.

## 처리

- 잊힌 작업 → 목록으로 보고하고, 지금 처리할지 / 다음 세션으로 넘길지(핸드오프·이슈화) 사용자에게 확인
- 상태판 불일치 → 갱신 제안 후 승인받아 수정
