## 감지 조건

현재 디렉토리가 git **워크트리**면 수행한다:

```bash
[ "$(git rev-parse --git-dir)" != "$(git rev-parse --git-common-dir)" ]
```

## 검사 절차

1. **원본 체크아웃 경로 확인**: `git rev-parse --git-common-dir`의 부모 디렉토리.
2. **유실 위험 파일 수집**: 워크트리에만 존재하는 비추적(untracked)·무시(ignored) 문서와 상태 파일을 찾는다. 대표 대상:
   - `.remember/` (개인 메모리·세션 기록)
   - `docs/superpowers/` (설계 문서·계획)
   - 그 밖의 gitignored 문서 디렉토리 (`git status --ignored --short`로 확인)

   커밋된 파일은 브랜치를 따라가므로 대상이 아니다. **커밋되지 않은 것만** 유실된다.
3. **원본과 대조**: 각 대상이 원본 체크아웃에 이미 있는지, 있다면 내용이 다른지 확인한다.

## 처리

- 이관 대상 목록과 각각의 처리 방식(신규 복사 / 병합)을 보여주고 승인받는다
- 원본에 같은 파일이 있고 내용이 다르면 **덮어쓰지 말고** diff를 보고해 어느 쪽을 살릴지 확인받는다 (append형 파일은 병합 제안)
- 승인 후 복사·병합을 수행하고 결과를 보고한다. 워크트리 삭제 여부는 이 체크의 소관이 아니다 — 이관 완료 사실만 알린다
