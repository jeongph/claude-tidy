## 감지 조건

다음 둘 다 해당하면 수행한다:

- 이슈 트래커 접근 가능: `gh` 사용 가능 + git 원격이 GitHub이거나, 프로젝트 지침에 다른 트래커(Notion, Linear 등)가 명시됨
- 이번 세션에서 이슈를 다뤘거나(해결, 분석, 언급), 이슈화할 만한 새 문제를 발견함

## 검사 절차

1. **다루던 이슈 최신화**: 세션에서 해결하거나 진행한 이슈를 나열하고 각각 확인한다.
   - 해결됐으면 닫혔는가 (커밋/PR의 auto-close 키워드 포함 여부도 확인)
   - 진행 중이면 현재 상태와 다음 단계가 이슈 코멘트로 남았는가
   - 분석 결과와 원인 규명이 이슈에 기록됐는가 (대화에만 있으면 유실됨)
2. **누락 이슈**: 세션 중 발견했지만 이번에 처리하지 않은 버그나 개선점이 이슈로 등록됐는지 확인한다.

## 처리

- 코멘트, 닫기, 신규 등록이 필요하면 **초안을 먼저 보여주고** 승인 후 실행한다 (외부로 나가는 내용이므로 반드시 확인)
- 이슈 본문이나 제목이 실제 상황과 어긋나 있으면 갱신을 제안한다
